# TODO: чат-тренер + живые данные на сайте

## К чему приходим

- **Основной интерфейс — чат с AI** (Claude в вебе/мобилке или CLI). Атлет пишет «что сегодня?», факт, проблемы; AI отвечает и правит JSON планов.
- **Git — долгосрочная БД.** Всё в одной ветке `main`. AI коммитит и пушит после каждой правки данных — ничего не теряется, даже если чат оборвётся.
- **Сайт — просмотр и бэкап.** Страницы читают JSON напрямую из репо (raw по SHA последнего коммита), поэтому новые данные видны сразу после пуша, без пересборки Pages.
- **GitHub Pages пересобирается только при изменении кода сайта** (html/js/assets), а не данных — лимит ~10 сборок в час не тратится.
- **Статистику считает JS страницы**, а не AI: сводка микроцикла и прогресс по упражнениям. AI только редактирует планы/факт и при необходимости словари (мышцы, алиасы серий).
- Ветка `workout` и squash-процесс больше не нужны.
